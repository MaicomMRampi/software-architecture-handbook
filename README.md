# Software Architecture Handbook

Repositório destinado ao estudo, documentação e desenvolvimento de projetos realizados ao longo da pós-graduação em **Arquitetura de Software e Soluções com IA**.

O conteúdo está organizado por módulos, acompanhando a evolução dos assuntos abordados durante a formação. Além dos materiais de estudo, o repositório reúne exemplos práticos, experimentos e projetos desenvolvidos para aplicar os conceitos de arquitetura de software.

Conteúdos relacionados aos fundamentos da arquitetura de software, conceitos arquiteturais, princípios, padrões e decisões que servem como base para a construção de sistemas mais organizados, sustentáveis e escaláveis.

Os demais módulos serão adicionados conforme o avanço da pós-graduação.

## Objetivo

A ideia deste repositório é servir como um **handbook pessoal de arquitetura de software**, reunindo conhecimentos e experiências adquiridos durante a pós-graduação em um único lugar.

O conteúdo será atualizado continuamente conforme novos conceitos, projetos e aprendizados forem incorporados.
