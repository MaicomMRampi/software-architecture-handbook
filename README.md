# Software Architecture Handbook

Repositório de estudo, documentação e projetos da pós-graduação em **Arquitetura de Software e Soluções com IA**.

A ideia é servir como um **handbook pessoal de arquitetura**: material de consulta e revisão para usar depois do curso.

## Como estudar com este material

Cada nota segue, sempre que possível, o mesmo formato:

1. **Resumo** em uma linha no topo;
2. **Conceito** com exemplos práticos (código, diagramas) e analogias;
3. **✅ Pontos-chave** para revisão rápida;
4. **❓ Perguntas de revisão** com a resposta escondida (clique para abrir), para praticar a memória;
5. **🔗 Relacionadas** e **📚 Referências** para aprofundar.

> Dica: para revisar um tema, leia só os Pontos-chave e tente responder às perguntas antes de abrir as respostas.
